## Upload order (App Store Connect)

1. Markets  
2. Event detail  
3. Watchlist  
4. Portfolio  
5. Share card  
6. Appearance  

First three appear most prominently in the store listing.

## How to upload (iPhone 6.5" Display)

1. App Store Connect → your app → the version → **App Store** tab → **Previews and Screenshots**.
2. Select **iPhone 6.5" Display** (or “View All Sizes in Media Manager”).
3. Drag these six JPEGs in the order above (or replace existing slots).
4. Do **not** upload PNGs with transparency; use these JPEGs as-is.
